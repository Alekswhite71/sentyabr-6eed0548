## Ежедневные уведомления

Работает так: страница добавляется на домашний экран как приложение, Виктория
разрешает уведомления, а GitHub Actions каждый день в 09:00 по Москве отправляет
ей пуш со счётчиком и фразой на этот день.

### Настройка (один раз)

1. **Ключи.** `node tools/gen-vapid.mjs` создаёт пару. Публичный ключ уже вписан
   в `docs/index.html`, приватный лежит в `vapid.local.json` и не коммитится.
2. **Секреты репозитория.** Нужны три:
   - `VAPID_PUBLIC_KEY`
   - `VAPID_PRIVATE_KEY`
   - `PUSH_SUB` — подписка Виктории
3. **Её телефон.** Открывает ссылку в Safari, добавляет на экран «Домой»,
   открывает уже с иконки, нажимает «Разрешить уведомления». Дальше страница
   покажет код — она отправляет его мне одной кнопкой.
4. **Код в секрет.** `gh secret set PUSH_SUB` и вставить полученную строку.
   Если подписок несколько, перечислить через запятую.

### Проверка

```bash
# посмотреть текст на сегодня, ничего не отправляя
DRY_RUN=1 node tools/send-push.mjs

# прогнать все даты от старта до конца поездки
node tools/test-schedule.mjs
```

Отправку можно запустить вручную: вкладка Actions → «Ежедневное уведомление» →
Run workflow. Там же есть переключатель «только показать текст».

### Что может пойти не так

- **Уведомления приходят только установленному приложению.** В обычной вкладке
  Safari iOS их не разрешит — это ограничение Apple, обойти нельзя.
- **Подписка иногда отзывается** (переустановка приложения, долгий простой).
  Тогда в логах Actions будет ошибка 404 или 410, и нужно заново пройти шаг 3.
- **Cron у GitHub неточный** — уведомление может прийти на 5 — 20 минут позже.

## Про море

Море сознательно **не входит в основной маршрут** — это заезд на один-два дня,
если захочется. На вкладке «Море» три варианта с честной ценой в километрах:

- **Ейск (Азов)** — 180 км от Ростова, 2 ч 45 мин. Самый простой заезд.
- **Геленджик (Чёрное)** — 713 км от Терскола, 11 ч. Требует ночёвки в Армавире.
- **Без моря** — круг остаётся ≈ 3 000 км и самым спокойным.
